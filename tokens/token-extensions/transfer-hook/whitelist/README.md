# Transfer Hook - Whitelist has moved

This example is now [Transfer Hook - Allow List](../allow-list/), in all three variants:

- [Anchor v1](../allow-list/anchor-v1/)
- [Anchor v2](../allow-list/anchor/)
- [Quasar](../allow-list/quasar/)

The new version has no size limit: each allowed wallet is its own account, rather than one entry in a single account capped at eleven. Each mint has its own allow list, which only the mint's authority can create.
