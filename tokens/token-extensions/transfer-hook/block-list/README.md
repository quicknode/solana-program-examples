# Transfer Hook - Block List has been replaced

This Pinocchio example has been removed. [Transfer Hook - Allow/Block List](../allow-block-list-token/) does what it did, one account per blocked wallet, and can also allow wallets or allow transfers below a threshold. It ships in Anchor v1, Anchor v2 and Quasar.

For a list that only allows wallets, see [Transfer Hook - Allow List](../allow-list/).
