# Vault Strategy has moved

This example is now **Managed Fund**, at [`finance/managed-fund`](../managed-fund/).

A vault strategy and a managed fund are the same product: investors deposit for shares priced at
net asset value, and a manager allocates the pool across a basket of approved assets. Some
platforms call it a vault or a vault strategy; the example now uses the finance term. The program,
its accounts and its instructions were renamed with it (`vault_strategy` is now `managed_fund`,
`Strategy` is now `Fund`, `initialize_strategy` is now `initialize_fund`).
